# Pokémon Dream Radar DS/DSi — BlocksDS

Private development repository for the user's Dream Radar demake.

Upload the contents of the extracted BlocksDS project into the **repository root** (`Makefile`, `source/`, `nitrofs/`, `scripts/`, `tools/`, and `tests/`). Keep this repository private because game assets are included.

The GitHub Actions workflow builds both `dream_radar_ds.nds` and `dream_radar_dsi.nds` and publishes the untested ROMs as artifacts if compilation succeeds.

This is an unfinished homebrew prototype, not a verified or fully faithful port.
